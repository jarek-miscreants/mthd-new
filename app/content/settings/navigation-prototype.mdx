# Graphite navigation prototype

This is the active prototype header's content source. The original header and
`settings/site.mdx` remain available. Edit the primary array to control the
centered links and menus, and the company block to control the right-hand menu.

Items with an `href` navigate directly on desktop and mobile. Platform and Developer now use menus with a page link and documentation link. Missions and Company open their subheader navigation panels.
On desktop, hovering either menu opens its panel; leaving the header closes it
after a short delay. Click, touch, and keyboard navigation are also supported.

Each dropdown has an introduction and one or more link groups. Optional `details`
groups sit under its introduction. External links can use `target: _blank`.

The three mission links currently share the existing `/missions` landing page.
Give them their individual destinations here as those pages are built.

The header renders the existing `LogoAnimation` component. Its visual behavior is
implemented separately in `GraphiteHeader.tsx` and `GraphiteHeader.module.css`.
